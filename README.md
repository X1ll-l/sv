# Swedish Learning

Тренажёр для построения шведских предложений: плитки слов, проверка порядка, три уровня подсказок, статистика и сброс прогресса.

## Структура
- `index.html` — готовая страница для GitHub Pages (всё в одном файле, сервер не нужен).
- `src/` — исходники: `index.html`, `style.css`, `app.js`. Из них собирается страница в корне.
- `data/` — корпус и пути подготовки: `exercises_all_drafts.json` (все упражнения-черновики), `translations_a1.py`, `selection_more.py`, `batch2.py`, `explain_a1.py`, `explain_more_a2.py`, `explain_rest.py`.

## Важно
Все переводы в данных — черновики, не проверены. Прогресс хранится в браузере на этом устройстве.
