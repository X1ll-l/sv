# SFI Swedish Trainer

Одностраничный тренажёр шведского (SFI): уровни B1, B2, C1, C2, D1, D2 по 200 предложений.

- `index.html` — готовая страница (GitHub Pages, ничего собирать не нужно).
- `source/SFI_B.json`, `SFI_C.json`, `SFI_D.json` — исходные предложения (шведский, русский перевод, тема).
- `source/build.py` — собирает плашки и правила порядка слов из исходников и вставляет их в `index.html`
  (блок `exercise-data`). Пути внутри скрипта указывают на `/home/claude/sfi`, перед запуском поправьте `BASE`.
- `source/fix_ru_and_topics.py` — правила тем для SFI D (по ключевым словам) и очистка переводов.
- `source/c1_rewrites.py` — сокращённые версии предложений C1 (уже применены к SFI_C.json).

Озвучка использует встроенный синтез речи браузера (шведский голос, если он есть на устройстве).
Прогресс хранится только в браузере (localStorage) и не отправляется никуда.
Предложения пока не проверены носителем шведского языка.
